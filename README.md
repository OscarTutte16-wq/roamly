# Roamly

A travel planner web app (installable PWA) with pin-point maps that work offline.

**Live:** https://oscartutte16-wq.github.io/roamly/

- Accurate search for villages as well as cities (OpenStreetMap Nominatim + Photon), with a pick list for same-name places
- Trips with destinations, day-by-day itinerary, packing list, budget & expenses, currency converter, weather, nearby places, tickets & bookings
- "Download for offline" saves the vector map, weather, places, rates and bookings on the device
- Warns you to download before visiting places likely to have poor signal

Everything is stored locally in your browser (localStorage + IndexedDB). No accounts, no API keys.
